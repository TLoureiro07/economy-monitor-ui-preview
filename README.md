# Economy Monitor - UI Preview

Standalone browser demo of the **Economy Monitor** admin dashboard. The commercial FiveM resource stays private — this repo shows only the front-end with mock data.

**Stack:** HTML · Vanilla JS · CSS · Chart.js · Vite (dev server)

## Run locally

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173` - no FiveM required.

## Screens included

- **Overview** — economy health score, wealth heatmap, money flow & daily insights
- **Statistics** — richest players/societies, rankings, largest transactions & charts
- **Players** — search, online list & player profile with activity timeline
- **Alerts** — configurable threshold rules & live alert queue

## Note

**Public demo only.** All player names, identifiers and transaction data are fictional. No server code, webhooks, or commercial assets are included.
